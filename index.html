คู่มือการ Deploy และเชื่อมต่อ Google Sheets

1. วิธีตั้งค่า Google Sheets API URL

นำ Web App URL ที่ได้จากการ Deploy Google Apps Script มาใส่ในตัวแปร GOOGLE_SHEET_API_URL ด้านบนสุดของ JavaScript

2. วิธี Deploy ขึ้น GitHub Pages ฟรี

  • อัปโหลดไฟล์นี้ตั้งชื่อว่า index.html ไปยัง GitHub Repository ของคุณ
  • ไปที่ Settings > Pages > เลือก Branch เป็น main แล้วกด Save
